# Symbols Studio

Arquivo visual independente de símbolos gráficos, baseado no *Symbol Sourcebook: An Authoritative Guide to International Graphic Symbols*, de Henry Dreyfuss (McGraw-Hill, 1972).

## O que o site contém hoje

- 15 estudos vetoriais esquemáticos feitos anteriormente.
- 118 símbolos vetorizados em SVG a partir das páginas impressas 34–36, 41 da p. 34, 41 da p. 35 e 36 da p. 36.
- 1.825 entradas textuais do índice impresso, com nomes e referências de páginas.
- As fichas vetoriais têm metadados de origem e os SVGs são exportados individualmente durante o build.
- O catálogo visual ainda não contém todos os desenhos das 296 páginas do livro. A primeira leva de vetorização é automática e requer revisão de contorno.

## Publicação no GitHub Pages

O workflow em `.github/workflows/pages.yml` publica os arquivos estáticos a cada push para `main`. Em **Settings → Pages**, mantenha Source como **GitHub Actions**.

URL: https://studio-gh.github.io/symbols-studio/

## Fonte e atribuição

Dreyfuss, Henry. *Symbol Sourcebook: An Authoritative Guide to International Graphic Symbols*. New York: McGraw-Hill, 1972.

As fichas são desenhos vetoriais reconstruídos a partir de páginas digitalizadas. O índice textual é uma ferramenta de localização, não um substituto do catálogo visual.
