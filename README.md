# Symbols Studio

Catálogo visual independente baseado no *Symbol Sourcebook: An Authoritative Guide to International Graphic Symbols*, de Henry Dreyfuss (McGraw-Hill, 1972).

## Catálogo visual
- 15 estudos vetoriais esquemáticos iniciais.
- Lote 01: 177 símbolos reconstruídos como SVG das páginas impressas 34–38. Os SVGs individuais são publicados na pasta `assets/symbols/` e exibidos no site.
- 1.825 entradas textuais do índice impresso. Essas entradas são referências, não desenhos.
- Os contornos foram gerados por vetorização automatizada e exigem revisão visual.
- O catálogo ainda não representa todos os símbolos das 296 páginas do livro. Os próximos lotes serão adicionados por páginas, com suas referências.
