# Symbols Studio

Catálogo visual baseado no *Symbol Sourcebook: An Authoritative Guide to International Graphic Symbols*, de Henry Dreyfuss (McGraw-Hill, 1972).

## Catálogo visual
- 15 estudos esquemáticos iniciais.
- **Lote 01: 177 símbolos reconstruídos como SVG** das páginas impressas 34–38.
- Cada símbolo aparece na galeria e tem um arquivo SVG individual com a página de origem.
- A vetorização é automatizada e exige revisão visual dos contornos.
- O índice textual inclui 1.825 referências e é uma ferramenta de localização, não substitui os desenhos.
- O catálogo ainda não cobre todas as 296 páginas do livro. Os lotes seguintes serão integrados à mesma galeria.

Site: https://studio-gh.github.io/symbols-studio/

Fonte: Dreyfuss, Henry. *Symbol Sourcebook: An Authoritative Guide to International Graphic Symbols*. New York: McGraw-Hill, 1972.
